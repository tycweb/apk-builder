How it actually works

  1. Your ZIP is unpacked on this server just long enough to patch app.json / eas.json.
  2. The server calls Expo's eas-cli on your behalf, authenticated with your token.
  3. eas-cli uploads your project straight to Expo's cloud build machines — the compiling happens there, not here.
  4. This page polls Expo's API for status until your APK is ready to download.
